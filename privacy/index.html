개인정보처리방침

시행일: 2026년 7월 12일

WAYZI(보험플레이)는 보험 질문 접수와 답변 제공에 필요한 범위에서 개인정보를 처리합니다.

1. 처리 목적

  • 질문 접수·게시·답변 제공
  • 비공개 질문의 본인 확인과 연락
  • 스팸·중복 등록 방지와 서비스 보안
  • 문의 데이터 백업과 운영 관리

2. 처리 항목

공개 질문분류, 제목, 질문 내용, 닉네임, 공개 게시 동의 기록
비공개 질문이름, 전화번호, 분류, 제목, 질문 내용
건강정보질문에 직접 작성한 질병, 진료, 투약, 검사, 입원·수술 관련 정보
자동 생성 정보접속 시각, 브라우저 정보, 유입정보, IP 주소를 변환한 보안 식별값
동의 기록동의 항목, 동의 버전, 동의 시각, 게시글 식별값

주민등록번호, 계좌번호, 상세 주소, 보험계약 비밀번호는 작성하지 마세요. 공개 질문은 검색엔진에 노출될 수 있습니다.

3. 동의

개인정보와 건강정보는 질문 등록 시 각각 동의를 받은 후 처리합니다. 공개 질문은 공개 게시 및 검색 노출 동의를 별도로 받습니다.

4. 보유 기간

공개 질문삭제 요청 또는 서비스 종료 시까지
비공개 질문등록일로부터 1년
동의 기록등록일로부터 1년
스팸 방지 기록목적 달성에 필요한 단기간

5. 외부 처리 서비스

Cloudflare웹사이트 호스팅, 보안, 트래픽 처리, 질문 데이터 저장
GoogleGoogle Apps Script와 연결된 저장공간을 통한 문의 백업·관리

외부 서비스의 처리 위치는 서비스 설정과 제공자의 데이터센터 정책에 따라 달라질 수 있습니다.

6. 공개 게시물

공개 질문의 제목, 닉네임과 질문 내용은 누구나 열람할 수 있고 검색엔진에 수집될 수 있습니다. 공개 질문에 실명, 연락처, 상세 병원명 등 개인 식별정보를 작성하지 마세요.

7. 이용자 권리

이용자는 개인정보의 열람, 정정, 삭제, 처리정지와 동의 철회를 요청할 수 있습니다. 본인 확인 후 게시물과 관련 정보를 삭제합니다.

8. 안전성 확보 조치

  • 관리자 인증과 보안 쿠키
  • 입력값 검증과 등록 횟수 제한
  • HTTPS 암호화 통신
  • 관리자·API 캐시 및 검색 차단
  • 보안 헤더와 악성 스크립트 방지
